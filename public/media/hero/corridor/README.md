# Hero corridor uploads

Demo agricultural illustrations are included here so the corridor is visible immediately. Replace them with your own photographs later using these filenames:

- `corridor-1.svg` - paddy field in morning light
- `corridor-2.svg` - farmer working in a paddy field
- `corridor-3.svg` - close-up of paddy grains
- `corridor-4.svg` - rows of young crops
- `corridor-5.svg` - agricultural landscape at golden hour
- `corridor-6.svg` - seed and crop close-up

To use photographs instead, replace the `.svg` paths with your uploaded `.jpg` paths in `src/data/media.ts`.
